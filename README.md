Vrinda Store Data Analysis
Introduction
This project focuses on transforming raw customer-submitted data into meaningful insights. By utilizing a systematic approach, the data underwent cleaning, enhancement, and visualization. The final outputs include actionable dashboards that highlight revenue sources, geographical trends, and product performance, enabling data-driven business decisions.
Purpose
The goal of the project is to:
1.	Transform raw data into a structured format for analysis.
2.	Provide actionable insights into customer demographics, sales trends, and regional performance.
3.	Deliver visual dashboards to aid in decision-making.
Scope
The scope of the project includes:
1.	Data Cleaning: Ensuring data accuracy and consistency by handling duplicates and formatting errors.
2.	Data Enhancement: Adding derived fields like age categories and regional classifications for more insightful analysis.
3.	Visualization: Creating dashboards to summarize key business metrics such as revenue, regional performance, and product trends.

Summary and Recommendations
1.	Summary:
•	The project successfully cleaned, structured, and visualized raw data.
•	Multi-line orders were preserved for both order-level and product-level insights.
•	Key metrics like total revenue, order count, and regional performance were highlighted.
2.	Recommendations:
•	Target Marketing:
	Focus on "Women" in the "Adults" age category, who form the majority of customers.
	Allocate more resources to high-performing channels like Myntra and Ajio.
•	Regional Expansion:
Increase presence in the North-East and South Zones, which show potential for growth.
•	Inventory Optimization:
Prioritize restocking high-demand SKUs based on historical quantity trends.
